:::success
瑞幸连接会把你的账号能力交给 Owlpost 的服务端保管，浏览器不会直接把凭证送到瑞幸接口。确认和付款始终由你亲自完成；没有你的确认，Owlpost 不会替你扣款。
:::

这项能力连接的是你自己的瑞幸账号。Owlpost 不代替瑞幸提供咖啡、配送、退款或售后服务，也不会从聊天 API 余额里扣除咖啡费用。瑞幸 MCP 当前只支持到店自取，不是外送。

## 开始前，请先准备好这些内容

### 1. 一个你自己的瑞幸账号

打开➡️ [瑞幸咖啡 AI 开放平台](https://open.lkcoffee.com/mcp)，使用瑞幸官方页面提供的登录方式进入。不同账号的开放能力可能不同；如果页面没有显示个人连接凭证或 MCP Token，不要从第三方网站购买或复制所谓“共享 Token”，请以官方页面和官方客服的说明为准。

### 2. 账号里的资料

在瑞幸官方 App 或小程序中，先把你平时会用到的内容准备好：

- 常用门店和城市位置；
- 常用取餐门店和城市位置；
- 会员优惠、优惠券和可用余额；
- 你愿意让角色参考的口味偏好（例如无糖、少冰、燕麦奶）。

Owlpost 不会替你新建门店、修改会员资料或领取优惠。实际能否购买，以瑞幸页面当时显示的门店营业状态、库存和价格为准。

### 3. 一枚只在官方页面取得的连接凭证

在瑞幸 AI 开放平台按页面指引申请或复制个人 MCP Token。它相当于一把能代表你访问瑞幸账号的钥匙：

- 不要发进聊天、群聊、截图、人物卡或世界书；
- 不要把它交给陌生人，也不要粘贴到不明网站；
- 不要手动添加 `Bearer`、引号或整段 JSON；
- 如果怀疑泄露，先在瑞幸官方平台撤销或重新生成，再回 Owlpost 重新绑定。

## 第一步：取得瑞幸 MCP Token

1. 打开➡️ [瑞幸咖啡 AI 开放平台](https://open.lkcoffee.com/mcp)。
2. 登录你要使用的瑞幸账号。
3. 在平台中查找“连接凭证”“MCP Token”或同类入口，按官方提示同意服务条款后生成凭证。
4. 只点击官方页面的复制按钮，暂时不要把完整凭证粘贴到聊天里。

如果你的账号看不到这些入口，说明该账号或当前平台版本尚未开放个人凭证。请不要使用网上流传的公共凭证；等待官方开放或联系瑞幸官方支持。

## 第二步：把 Token 绑定到 Owlpost

回到 Owlpost：

1. 打开“设置”。
2. 进入“API 设置”。
3. 找到“**Owlpost · 餐点信使**”，展开“瑞幸咖啡”。
4. 把刚复制的凭证粘贴到“瑞幸 MCP Token”。
5. 点击“验证并绑定”。
6. 显示“已绑定，可以使用”后，再按需要打开“允许角色帮我准备瑞幸订单”。

验证只会检查瑞幸官方连接是否能建立，以及当前账号是否返回点单所需的工具清单；它不会创建订单、不会打开付款页。验证结束后输入框会清空，完整凭证不会写入聊天消息、人物资料或冥想盆导出文件。

同一个 Owlpost 游戏账号可以在自己的其他设备继续使用这条连接。退出 Owlpost 账号后，当前设备不会继续使用上一个账号的瑞幸连接。

## 第三步：在私聊中使用

瑞幸的连接入口已经独立于麦当劳，开关和凭证不会互相影响。当前版本支持“查门店 → 查饮品 → 预览价格 → 生成订单 → 返回付款入口 → 查询回执”的完整链路，第一阶段只支持**到店取餐**。

触发方式沿用餐点信使：在普通角色私聊中明确说出想喝什么、到哪家门店取，并明确同意让角色准备真实订单草案。瑞幸当前只能到店自取，不会送到家。角色会用自己的语气回应，然后生成一张确认函；你核对门店、饮品、数量和金额后点击确认。订单送到门店后，确认函会出现“去付款”，付款必须由你本人完成；付款后还要到该门店取走咖啡。付款后点“刷新状态”，或回到页面等待自动核对门店回执。

确认函不是普通推荐，也不是自动扣款授权。遇到门店有多个、饮品名称不明确、价格或库存无法核对时，会先请你补充或把确认函停在“正在核对”，不会拿猜测代替真实订单。

## 连接开关、重新绑定与解除

- **关闭开关**：暂不允许角色准备新的瑞幸订单；已经存在的官方订单仍以瑞幸官方渠道为准。
- **检查连接**：只重新检查凭证和工具清单，不创建订单。
- **重新绑定**：先验证新凭证，成功后才会替换旧连接。
- **需要重新确认**：通常表示凭证已失效、被撤销，或瑞幸官方接口暂时拒绝访问。
- **解除绑定**：停止使用这枚凭证；已经存在的瑞幸订单仍要去瑞幸官方 App、小程序或客服处理。

## 常见问题

### 显示“点单邮路暂未开放”

这表示当前 Owlpost 版本或服务器还没有打开瑞幸能力。保持开关关闭即可；反复粘贴 Token 不会解决这个问题。

### Token 验证失败

先确认凭证来自瑞幸官方平台，没有多复制空格、引号、`Bearer` 前缀或整段 JSON。若官方平台本身也无法使用，请联系瑞幸官方支持，不要把凭证交给别人代查。

### 绑定成功但没有订单卡

连接成功只代表账号和工具清单可用，不等于订单已经创建。瑞幸的门店、商品、库存、价格和订单状态还要经过真实账号的只读实测；在订单能力开放前，页面不会把连接状态冒充成下单成功。

### 付款后订单状态没有变化

以瑞幸官方 App、小程序或订单页面为准，并保留付款凭证。Owlpost 的订单卡出现“正在核对”时，不要重复付款；先等待官方订单状态稳定，再点击“刷新状态”。如果仍然没有回执，直接以瑞幸官方订单为准，不要再次点击付款。

### 为什么只能到店自取

当前公开的瑞幸 MCP 只提供门店、饮品、价格、创单和订单状态能力，没有可供我们核对的配送地址和配送方式。所以这一版明确只做到店自取，不把外送假装成已经支持。后续如官方接口稳定支持其他取餐方式，会在公告和教程中另行说明。

## 使用范围与安全提醒

- 使用瑞幸 AI 开放平台前，请阅读并遵守瑞幸官方服务条款、隐私政策和 MCP 规则。
- Owlpost 与瑞幸不存在教程之外的品牌合作或联名关系。
- 咖啡、价格、优惠、门店、付款、取餐、取消和售后，以瑞幸官方信息为准。
- 永远不要把 MCP Token、完整地址、电话或付款资料发给角色或其他玩家。

:::success
最安全的顺序是：先在瑞幸官方账号准备资料 → 取得个人 Token → 回 Owlpost 验证绑定 → 打开开关 → 在私聊里说清饮品和取餐门店 → 核对确认函 → 亲自确认并在瑞幸官方页面付款 → 刷新订单回执。
