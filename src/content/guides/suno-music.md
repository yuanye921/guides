:::success

角色写歌使用 **open.suno.cn 提供的第三方音乐 API**。你需要自己注册、自己充值、自己保管 API Key；Owlpost 不代充，也不会从聊天 API 余额里扣音乐费用。

这不是 Suno.com 的登录入口。教程里要创建的是 open.suno.cn 商户后台的 **access_key**，不要填写 Suno.com 密码或登录 Cookie。

:::

## 第一步：注册 open.suno.cn 账号

打开➡️ [open.suno.cn 商户注册](https://open.suno.cn/merchant/register)。

注册页会要求填写商家名称、负责人姓名、手机号、短信验证码和登录密码，并勾选服务协议与隐私政策。个人使用时，商家名称可以填写方便自己辨认的名称。

注册完成后，使用➡️ [商户后台登录页](https://open.suno.cn/merchant/login)登录。

:::color2

公开页面显示，新注册账号会赠送一小笔测试积分。赠送数量、有效期和活动规则可能调整，请以注册页和后台实际显示为准。

:::

## 第二步：创建 API Key

1. 登录商户后台。
2. 打开左侧的 **API 密钥管理**。
3. 点击 **创建新 API 密钥**。
4. 创建成功后，立刻复制完整的 `access_key`，先保存到自己的密码管理器或安全备忘录。

:::danger

API Key 就像这家音乐账户的钥匙。不要把它发到聊天、群组、截图、帖子或客服对话里，也不要把完整 Key 提交给任何声称可以“代测试”的陌生网页。

如果 Key 泄露，请回到后台撤销旧 Key，再创建一把新的。不要把 Suno.com 的密码、短信验证码或登录 Cookie 粘贴到 Owlpost。

:::

## 第三步：给音乐账户充值

登录后台后，找到 **钱包、余额或积分** 页面，按照页面提示充值。当前平台标示的计费方式是：

- **音乐生成：36 积分/次**
- **充值比例：`1:100`（50 起充）**

充值方式、手续费、到账时间以及后续价格调整，以充值页面当时显示为准。

充值前可以先打开➡️ [API 在线测试](https://open.suno.cn/)，使用余额查询功能确认当前账户还有多少积分。余额查询本身不生成歌曲，也不消耗生成额度。

open.suno.cn 的 API 文档说明，音乐生成通常会返回两个任务编号，之后需要等待任务完成；余额不足时会返回 402。遇到充值没到账、退款或扣费异常，应直接联系该平台处理，Owlpost 无法替你操作第三方账户。

更多接口说明可以查看➡️ [open.suno.cn API 使用指南](https://open.suno.cn/api-guide)。

## 第四步：把 Key 填回 Owlpost

1. 打开 Owlpost 首页右下角的 **齿轮**。
2. 进入 **API** 设置。
3. 找到 **「🎵 角色写歌（第三方接口）」**。
4. 把刚才复制的 `access_key` 粘贴进 **音乐 API Key** 输入框。
5. 点击 **保存设置**。

这把 Key 会跟随 Owlpost 的云存档和冥想盆存档一起转移，换设备恢复存档后不用再次填写；它不会写进聊天正文。网页或 PWA 生成音乐时，请求会经过 Owlpost 的轻量转发接口，再交给 open.suno.cn。

:::danger

既然 Key 会进入存档和导出文件，请把存档文件当作含有 API 密码的文件保管，不要发给别人或上传到公开网盘。导出给别人前，先确认是否需要删掉自己的音乐 Key。

:::

## 第五步：让角色写歌

在私聊或群聊中明确告诉角色你想创作歌曲，例如：

- “请为我们写一首关于雨夜告白的歌。”
- “帮我创作一首轻快的生日歌，想要钢琴和女声。”
- “作曲：主题是离开霍格沃茨前的告别。”

角色会先用自己的口吻回应，再开始生成。每次生成通常会得到两个版本，完成后会在聊天里出现播放器。音乐生成需要等待第三方平台处理，可能需要几分钟；等待时聊天里会先放一个占位提示，完成后自动换成播放器。

生成的音乐会优先保存到 Owlpost 的个人私有音乐存档，聊天播放器只取短时播放地址；不会因为播放就自动把整首歌复制进浏览器缓存。需要带走文件时，再点播放器上的 **保存到设备**。

只聊天、提到喜欢某首歌、或让角色播放已有歌曲，不会自动扣积分生成新歌；必须明确提出写歌、创作、作曲或制作歌曲的要求。

## 费用、作品和使用边界

- 音乐费用由你在 open.suno.cn 的账户承担，Owlpost 不代充、不经手退款，也不会从聊天 API 余额扣款。
- 当前音乐生成费用为 **36 积分/次**，充值比例为 **`1:100`（50 起充）**。平台后续可能调整价格，实际扣费和生成失败是否退回积分，以 open.suno.cn 后台的实时规则与任务记录为准。
- 歌词、声音、发布和商用权限由你与第三方平台当前条款决定。不要把没有授权的歌词、录音或他人作品拿去生成、翻唱或发布。
- open.suno.cn 的公开页面把自己描述为第三方 API 源服务商；它不是 Owlpost 自营服务。平台域名、价格、接口和服务状态变化时，以其官网公告为准。

## 常见问题

### 提示“请先填写音乐 API Key”

回到 **设置 → API → 角色写歌**，确认已经粘贴完整的 `access_key` 并点击保存。不要把 API Key 填到主聊天 API、MiniMax 或 TikHub 输入框里。

### 提示 Key 无效或 401

检查有没有复制多余空格，确认 Key 没有被撤销，并确认使用的是 open.suno.cn 商户后台创建的 `access_key`。仍然无效时，在后台撤销旧 Key，再创建新的。

### 提示积分不足或 402

登录 open.suno.cn 商户后台查看余额和充值记录。充值到账后，再重新发送写歌请求；不要连续重复点击，避免重复提交任务。

### 歌曲生成了，但播放器打不开

先等待几秒后点击“再听一次”。第三方返回的音频地址可能会过期或临时不可用；如果平台后台能正常播放，重新生成一次通常可以拿到新的地址。

### 为什么有时只有一分钟左右

open.suno.cn 的公开接口说明了任务和音频地址的返回方式，没有写死“一分钟”的统一上限。歌曲长度主要受歌词篇幅、段落结构和平台当时采用的模型影响；只给很短的歌词时，返回短片段很正常。Owlpost 会向角色要求约 2 到 3 分钟的完整结构（前奏、两段以上主歌、副歌、桥段和尾奏），但第三方平台仍可能因模型或服务状态返回较短版本。

### 我想删除 Key

在 Owlpost 的音乐 API Key 输入框清空并保存；如果担心旧 Key 已经泄露，再到 open.suno.cn 后台把旧 Key 撤销。

:::

配置完成后，就可以把一段故事、一句祝福或一个场景交给角色，让 TA 写一首只属于你们的歌了。
