## 开启记忆

自带的预言家记忆可以自由开关，也可以[关闭内置记忆，改用自己的记忆插件](#改用其他记忆插件)。

点击头栏从左往右第 **8** 个 **星光书本（预言家记忆）**，直接打开记忆面板。它位于 **积木（扩展程序）** 与 **笑脸（用户人设）** 之间。

## 翻看与纠正

五个分册各管一件事：

| 分册 | 适合回看什么 |
| --- | --- |
| **往事** | 剧情摘要、章节与重要转折 |
| **人物** | 身份、关系变化、各自知道的事 |
| **物品** | 获得、赠送、消耗，以及东西在谁手里 |
| **足迹** | 去过的地点、场景与故事里明确提到的时间 |
| **约定** | 承诺、计划、伏笔，以及是否已经完成 |

记错了，就打开对应笔记纠正后保存。手动纠正会单独保留，不会被下一次自动整理悄悄改回去。重要的笔记可以固定。

秘密笔记要把 **知情范围** 改成 **指定知情人**，只勾选真正知道这件事的人。同名人物会附带身份说明，别只看名字。

## 整理旧故事

点 **轮次**，先从下拉框选中对应剧情，并核对下方原文预览。

- **重新整理**：重看选中的一轮，会再次调用自己的 AI 接口。
- **排除番外**：这一轮不再记入正篇；聊天原文保留。
- **补记历史**：补记尚未整理的已完成剧情，可能需要多次调用。

## 带记忆续聊

点 **续聊**，再确认 **续聊**，新聊天会带走整理后的记忆与最近三轮原文，原聊天保留。

不同聊天平时各自记事。需要搬运时，可以导出、导入预言家记忆文件；已有的文字总结也可以粘贴，再选它对应的剧情范围。

导入前先确定这份往事放在哪里：

| 放置方式 | 什么时候选 |
| --- | --- |
| **在全部现有原文之前** | 这是另一篇故事的前情，当前聊天还没有演过这些内容。 |
| **对应一段现有原文** | 总结的是当前聊天里已有的一段，选择它对应的起止轮次。 |

导入会替换已有的历史底稿；导入记忆文件还会替换其中的手写笔记。需要保留旧册子时，先导出一份。聊天原文不会被删除。

只有一段文字总结时，点 **导入 → 粘贴旧总结**，填写内容并选择起止轮次。下方还可选择分册与知情范围，最后点 **保存总结**。

## 接口设置

默认沿用当前聊天的接口与模型。需要分开使用时，在记忆设置中选择独立整理接口，填写地址、模型与密钥。

独立接口须兼容 OpenAI。主聊天使用文本补全等其他连接类型时，也需要配置独立整理接口；独立接口失败不会自动改用聊天接口。

## 改用其他记忆插件

**可以关闭自带的预言家记忆，使用自己安装的其他记忆插件。**

1. 点击头栏的 **星光书本（预言家记忆）**，将右上角的 **已开启** 开关切换为 **已关闭**。如果已经显示 **已关闭**，无需再点。
2. 按所用插件的教程安装、设置并启用自己的记忆插件。

这个开关对账号内所有聊天生效，已有笔记仍保留。旁边的 **关闭** 只收起面板，不会关闭内置记忆。

## 常见问题

<details><summary>什么时候会记下上一段故事？</summary><p>发送下一条消息时，整理上一轮已经定稿的剧情。重写、切换候选回复时，不会把正在替换的内容记进去。</p></details>

<details><summary>原来的聊天会被删掉吗？</summary><p>不会。完整原文仍可查看和导出；最近三轮也会保留原文供聊天使用。</p></details>

<details><summary>整理失败了怎么办？</summary><p>原文和上一份有效记忆会保留。检查接口后再试；若提示内容放不下，可以先补记旧故事或调整上下文。</p></details>

<details><summary>导入后又修改了对应剧情，怎么办？</summary><p>旧总结可能已经对不上原文。重新导入正确的记忆文件，或粘贴修订后的总结，再选一次对应范围；确认前先保留原文继续。</p></details>

<details><summary>关闭网页以后还会扣费吗？</summary><p>关闭后不再发起新的整理。已经发出的请求可能已经被接口服务商计费。</p></details>

<details><summary>可以不用自带的记忆插件吗？</summary><p>可以。先把预言家记忆右上角的开关切换为「已关闭」，再使用自己的记忆插件；已有笔记会保留。具体步骤见<a href="#改用其他记忆插件">改用其他记忆插件</a>。</p></details>

<details><summary>能和其他摘要插件一起开吗？</summary><p>建议选择一套负责记忆的插件，避免两套功能同时裁剪同一段历史。遇到冲突提示时，可以关闭内置记忆，继续使用自己的插件。</p></details>

<details><summary>角色卡用了动态变量，补记旧故事要注意什么？</summary><p>只靠动态变量表达的设定，补记时可能读不到。重要身份和约定请写成明确文字，补记后核对，必要时手动纠正。</p></details>

<details><summary>手机和电脑能看到同一本记忆吗？</summary><p>能，记忆随该聊天保存。先等保存完成，再到另一台设备继续。自动备份也会一同保存记忆，无需另做备份。</p></details>

<details><summary>固定的笔记会一直发给 AI 吗？</summary><p>固定会提高它的保留优先级，但仍受当前模型能容纳的内容限制。重要设定也请放在角色卡或世界书里。</p></details>
