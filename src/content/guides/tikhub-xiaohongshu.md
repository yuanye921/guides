:::success

配置完成后，你可以把小红书分享文案或链接直接发给角色。角色能读到笔记的标题、正文、作者、热门评论，并在模型支持看图时看到笔记前几张图片。

TikHub 是独立服务：**Owlpost 不代收这部分费用，也不会从你的聊天 API 余额里扣钱。**

:::

## 第一步：注册并验证 TikHub 账号

打开➡️ [TikHub 注册页面](https://user.tikhub.io/register)，用常用邮箱注册。

![](/assets/tikhub-xiaohongshu/step-01-register.png)

注册后到邮箱里找到验证信，点击确认链接。没有收到时，可以检查垃圾邮件箱，并确认邮箱地址有没有拼错。

:::color2

TikHub 的官方入门页会更新注册福利、充值方式和使用规则；遇到页面变化时，以➡️ [TikHub 注册与充值说明](https://tikhub.io/getting-started)为准。

:::

## 第二步：充值

登录 TikHub 后，进入账户的充值页面，选择适合自己的方式。TikHub 当前的官方说明列出了 PayPal、支付宝和 USDT 等方式；可用方式、限额和到账规则可能变化，请以充值页当时显示的内容为准。

:::danger

如果使用 USDT，请仔细阅读页面的金额和网络手续费说明。不要凭经验自行少付，也不要向教程之外的陌生地址转账。

:::

## 第三步：创建并保存 API Token

1. 登录 TikHub 后进入 API Token／密钥管理页面。
2. 点击创建新的 Token，名称可以写成 `Owlpost`，方便以后辨认。
3. 创建成功后立刻复制，并先保存到自己的密码管理器或安全备忘录。
4. 不要把 Token 发到群聊、截图、帖子或客服对话里。

:::danger

密钥创建页可能只在当时完整显示一次。关掉页面前一定要复制保存；如果已经遗失，请在 TikHub 后台撤销旧 Token，再创建一个新的。

:::

## 第四步：在 Owlpost 填写 Key

回到 Owlpost，点击首页右下角的 **齿轮**，进入 **魔杖配置**，向下找到 **「📕 小红书阅读凭证（TikHub）」**。

![](/assets/tikhub-xiaohongshu/step-02-owlpost-settings.png)

把刚才复制的 TikHub API Token 粘贴进输入框，然后点击 **保存设置**。

这把 Key 会保存在本机，并跟随你的 Owlpost 云存档；它不会写进聊天消息，也不会放进冥想盆导出文件。请继续把它当成银行卡密码一样保管。

在 Owlpost 安卓版里，请求会由手机的原生网络直接发给 TikHub；在网页或 PWA 里，为了绕开浏览器的跨域限制，请求会经过 Owlpost 网站自己的轻量转发接口。这个接口只负责当场转交请求，不会使用 New API 计费，也不会替你保存或共用 TikHub Key。

## 第五步：分享给角色

### 私聊

1. 在小红书里点 **分享**，选择 **复制链接**。
2. 回到角色私聊，把整段分享文案或链接粘贴进输入框。
3. 你可以在链接前后加自己的话，例如：“你看看这家店怎么样？”
4. 发送后，消息下方会出现笔记卡片；角色会结合笔记、热门评论和能够读取的图片回答。

### 群聊

1. 把分享文案或链接粘贴到群聊并发送。
2. 自动群聊会让本轮被选中的角色共读同一份笔记。
3. 手动群聊可以在发送后点击某个角色，让 TA 回应。
4. 多个角色共用已经展开的笔记，不会因为群里多一个角色就重复购买一次详情和评论。

:::color1

一条消息里放了多个小红书链接时，只会展开第一个。视频笔记会读标题、正文、封面和评论，但不会在聊天里播放视频。

:::

## 费用是怎么计算的？

每次成功分享通常包含：

- 1 次笔记详情请求；
- 1 次评论请求。

如果笔记详情读取失败，Owlpost 不会继续请求评论，避免多花一次。图片会复用笔记资料中的公开图片地址，不会再次调用 TikHub。

TikHub 可能调整接口单价，因此本教程不写死金额。使用前请在 TikHub API 市场或接口页面查看当时价格：

- [小红书笔记详情接口](https://docs.tikhub.io/420136391e0)
- [小红书评论接口](https://docs.tikhub.io/420136394e0)

## 常见问题

### 提示 Key 无效

检查复制时有没有多出空格，确认 Token 没有被撤销。仍然无效时，在 TikHub 后台创建新 Token，回到 Owlpost 替换并保存。

### 提示余额不足

先到 TikHub 查看余额和充值记录。充值到账后再发送一次；之前没发出去的文字会留在输入框里。

### 链接失效或笔记打不开

确认链接来自 `xiaohongshu.com`、`xhslink.com` 或 `xhslink.cn`。笔记被作者删除、设为不可见或短链接过期时，Owlpost 无法展开。

### 卡片出现了，但显示“评论暂时没有展开”

这表示笔记正文已经读到，只是评论接口暂时失败。消息仍会正常发送，角色可以先根据标题和正文回答；稍后重新分享可再试一次。

### 角色只读了文字，没有描述图片

你当前使用的聊天模型可能不支持看图，或者原图暂时失效。Owlpost 会自动退回文字、正文和评论阅读，不会让整条回复失败。想让角色看图，请换成明确支持视觉输入的模型。

### 分享后一直没有展开

先检查 TikHub Key 和余额，再确认网络正常。安卓用户需要能够访问 TikHub 为中国大陆提供的接口域名；网页或 PWA 用户需要先登录 Owlpost，让网站的轻量转发接口确认身份。为防止误扣，TikHub 的付费请求不会自动重试；请等提示结束后再手动发送一次。

:::success

现在，把一篇你真的想和 TA 讨论的笔记寄过去吧。角色读到的是你分享的资料，不会把笔记里的“忽略规则”“更换身份”等文字当成命令。

:::
