## 二、快速上手使用：两步开聊

新手只需要完成以下两步，就能立刻开启你的第一段故事：

### 第一步：配置 API（配上 AI 大脑）

此处以 **预言家 API** 为例：

1. **点开顶部第 2 个图标「插头」**。
2. **选择接口预设**：在「接口预设」中选择 **预言家 API**。
3. **选择服务器线路**：
   - 下方提供 **香港线路** 与 **北京线路**。
   - 💡 **不开加速器/梯子的国内用户，强烈推荐选择北京线路**，稳定免翻直连。
4. **填入密钥**：
   - 选好线路后，接口地址 URL 会自动填好，无需修改。
   - 在 **自定义 API 密钥** 栏粘贴你的 API 密钥（Key，以 `sk-` 开头），不要填会员卡密。
5. **连接并选择模型**：
   - 点击 **连接** 按钮，连接成功后，在下方的 **可用模型** 下拉列表中挑选你要使用的模型（如 Claude 3.5 Sonnet、GPT-4o、DeepSeek 等）。
   - 💡 密钥标题旁会自动显示当前账户余额。

### 第二步：选择角色卡，开始聊天

1. **点击顶部第 10 个图标「角色管理」**：
   - 打开角色列表，挑一张你想聊的角色卡点击进入。
   - 如果想导入自己在社区下载的角色卡，点击列表上方的托盘图标 **从文件导入角色**（必须是原始 PNG 格式）。
2. **首次弹窗一律选「是」**：
   - 有的角色卡在第一次打开时，会弹窗询问是否要 **启动配套正则**、**自动绑定世界书**。
   - **新手无需纠结，无脑选择“是 / 同意”即可！** 系统会自动替你把配套规则与世界书绑定好，省去手动折腾。
3. **切换回聊天界面**：
   - 📱 **手机端特别提醒**：在手机上选好角色卡后，**需要再点一下顶部的角色卡图标**，侧边栏才会收起并切回聊天窗口。
4. **发送消息，开启故事**：
   - 底部输入框中输入你想说的话或进行的行动，点击右侧纸飞机发送。
   - AI 开始打字回复，你的第一段故事就正式启程了！

## 三、新手必看避坑指南

<div class="tavern-checklist">
  <strong>新手请牢记这 3 点</strong>
  <ul>
    <li><b>角色卡必须是原图 PNG 格式</b>：角色卡的数据嵌入在图片的底层代码里。绝对不能把 <code>.jpg</code>、<code>.webp</code> 或 <code>.txt</code> 文件手动改后缀改成 <code>.png</code>；从聊天软件接收卡片时记得保存原图或原文件，避免被压缩损坏。</li>
    <li><b>看到开场白 ≠ API 连通了</b>：点开角色卡时看到的欢迎语是卡片作者预置的文本，不消耗 API 额度，也不能证明接口已经通畅。只有你自己发出一句话后，能正常收到 AI 的打字回复，才代表连接彻底成功。</li>
    <li><b>离开或换设备前手动保存一次</b>：准备在手机和电脑之间切换玩耍时，点击酒馆左下角「我的账号」旁的 <b>保存到云端</b>，看到「已保存到云端」提示后再换设备登录即可，无需等待备份轮次。</li>
  </ul>
</div>

## 四、遇到问题先看这里

<details class="tavern-fold"><summary>能看到开场白，发消息却没有回复？</summary>

1. 打开插头面板：检查是否点击了 **连接**、**可用模型** 是否空着（获取到模型列表后，不会自动替你选，需要手动点选一个）。
2. 检查密钥：自定义 API 密钥是否粘贴完整、前后是否有误复制的多余空格。
3. 检查余额：API 站账户余额是否充足。

</details>

<details class="tavern-fold"><summary>提示 401 / 403、429、模型不存在？</summary>

- **401 / 403**：密钥无效或未通过验证。请检查密钥是否正确，以及是否属于当前填写的接口地址。
- **429**：请求过于频繁被服务商限流，或额度耗尽。稍等重试或前往 API 站充值。
- **模型不存在 / 无可用模型**：重新在插头面板点击「连接」刷新模型列表，并在列表中选择有效的模型名称。
- **连接超时 / 5xx**：国内不开梯子的用户，请在插头面板切换至 **北京线路** 后重新点击连接。

</details>

<details class="tavern-fold"><summary>手机上选了角色卡，聊天界面在哪？</summary>

手机屏幕宽度有限，角色面板会覆盖整个屏幕。选好角色卡后，**再次点击顶部导航栏的角色卡图标**，侧边栏便会自动收起，露出底部的聊天窗口。

</details>

<details class="tavern-fold"><summary>想换独家美化主题在哪里换？</summary>

点击顶部第 5 个图标 **人物与齿轮（用户设置）**，在设置中即可看到预言家云酒馆独家内置的三套主题风格，一键切换即可获得精美外观。

</details>
