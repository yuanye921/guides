:::success
配置完成后，你可以在 Owlpost 的普通角色私聊里，请角色按你的要求准备麦当劳餐点。角色会先送来一张“餐点确认函”，只有你亲手确认后才会向麦当劳创建订单，付款也始终在麦当劳官方页面完成。
:::

这项功能连接的是你自己的麦当劳中国账号。Owlpost 不代替麦当劳提供餐品、配送或售后服务，也不会从聊天 API 余额里扣除餐费。

## 开始前，请先准备好这些内容

### 1. 一个可以接收短信的中国大陆手机号

麦当劳 MCP 平台使用手机号验证码登录。还没有麦当劳会员账号也没关系：在登录页同意会员协议、隐私政策和使用条款后，未注册的手机号会自动创建会员账号。

麦当劳 MCP 服务目前面向中国大陆地区使用，不含港澳台。实际能否配送，还要以你选择的地址、门店营业时间和麦当劳页面当时显示的范围为准。

### 2. 至少一条完整的外送地址

如果你想让角色准备麦乐送订单，请先在同一个麦当劳账号里保存好配送地址。建议在麦当劳中国官方 App、小程序或点餐页面检查以下内容：

- 城市名称正确；
- 联系人姓名正确；
- 联系电话是可以接听的 11 位手机号；
- 小区、街道或楼宇地址完整；
- 楼栋、单元、房号等门牌信息完整。

Owlpost 当前只会从你的麦当劳账号中读取已有地址并让你选择，**不会替你新建或修改配送地址**。如果账号里没有地址，请先去麦当劳官方入口补好，再回到游戏。

为了保护隐私，聊天和餐点确认函只显示遮挡后的地点。和角色说“送到家里”或“用我保存的公司地址”即可；如果有多条地址，确认函会让你从遮挡后的选项中亲自选择。没有必要把完整门牌号重新发进聊天。

### 3. 账号中已有的优惠券

如果你允许使用“当前可用的最佳优惠”，角色会查看这个账号在所选门店已经拥有且适用于当前餐点的优惠券，并以麦当劳最终核价为准。

Owlpost 不会替你领取新券、兑换积分或购买积分商品。想使用某张券时，先确认它已经在同一个麦当劳账号里，并留意适用门店、时段、餐品和有效期。

## 第一步：登录或注册麦当劳账号

打开➡️ [麦当劳中国 MCP 平台](https://open.mcd.cn/mcp/auth)。

1. 点击页面右上角的“登录”。
2. 输入手机号并获取短信验证码。
3. 阅读并勾选麦当劳会员协议、隐私政策和使用条款。
4. 完成登录；首次使用的手机号会按页面说明创建会员账号。

请使用已经保存配送地址、优惠券和会员资料的那个手机号。换一个手机号登录，会得到另一个独立的麦当劳账号。

## 第二步：申请 MCP Token

登录成功后，页面右上角的“登录”会变成“控制台”。

1. 打开“控制台”。
2. 点击“激活”，申请 MCP Token。
3. 阅读并同意麦当劳 MCP 服务协议。
4. 申请成功后，点击复制 Token。

Token 就像一把可以代表你访问麦当劳账号的私人钥匙：

- 不要发进聊天、群聊、截图、人物卡或世界书；
- 不要把它交给陌生人，也不要粘贴到不明网站；
- 不要在 Token 前手动添加 `Bearer`，也不要连同引号一起复制；
- 如果怀疑泄露，请在麦当劳 MCP 控制台处理旧 Token，再回 Owlpost 重新绑定。

麦当劳当前规定每个 Token 每分钟最多允许 600 次请求。Owlpost 会限制自己的调用频率，但仍不要在短时间内反复点击确认或刷新。

遇到官方页面改版时，请以➡️ [麦当劳 MCP 官方接入文档](https://open.mcd.cn/mcp/doc)为准。

## 第三步：把 Token 绑定到 Owlpost

回到 Owlpost：

1. 打开“设置”。
2. 进入“API 设置”。
3. 找到“麦当劳连接”。
4. 把刚复制的 Token 粘贴到“麦当劳 MCP Token”。
5. 点击“验证并绑定”。
6. 显示“已绑定，可以使用”后，打开“允许角色帮我准备麦当劳订单”。

验证时只会读取麦当劳提供的工具清单，**不会创建订单，也不会打开付款页**。验证结束后，输入框会立即清空；完整 Token 不会出现在聊天消息、普通云存档或冥想盆导出文件里。

同一个 Owlpost 游戏账号可以在自己的其他设备继续使用这条连接，不需要每台设备都重新粘贴 Token。退出游戏账号后，当前设备不会继续使用上一个账号的麦当劳连接。

## 第四步：在私聊中触发点餐

这项能力只在普通角色私聊中工作。群聊、特殊房间、试用聊天和其他不合适的场景不会创建真实餐点草案。

角色可以自然建议吃什么，但“我饿了”“想吃汉堡”之类的话不会直接触发点餐。你必须明确表示：**同意角色现在为真实订单准备草案**。

可以这样说：

- “可以，帮我准备一份麦辣鸡腿堡和中薯，外送，用账号里保存的地址。”
- “你帮我挑一份 50 元以内、不含花生的套餐，到店取餐。可以开始准备确认函。”
- “就按你刚才推荐的准备吧，使用已有的合适优惠券，但先给我确认，不要直接付款。”

说清楚这些内容会更顺利：

- 外送、到店取餐还是得来速；
- 餐品名称、数量和明确规格；
- 预算；
- 使用哪条已保存地址或哪家门店；
- 是否使用账号中已有的合适优惠券；
- 预约时间；
- 过敏原、忌口和不能接受的配料。

过敏与饮食要求属于高风险信息。角色不确定时会继续追问，无法从麦当劳当前餐品资料中确认时也不会替你猜。严重过敏者请务必再向麦当劳门店确认，不能只依赖 AI 或页面标签。

## 第五步：检查“餐点确认函”

角色准备好草案后，同一条消息里会出现餐点确认函。你会看到餐品、数量、取餐方式、遮挡后的地点、优惠和最终应付金额。

请逐项检查：

- 餐品、规格和数量；
- 外送地址或取餐门店；
- 预约时间；
- 优惠券是否符合预期；
- 配送费、优惠金额和应付总额；
- 过敏和忌口复核结果。

如果地址、门店、餐品或预约时间存在多个可能，确认函会给出选项。选完后角色会在原来的确认函上继续更新，不会偷偷再创建一张订单。

草案阶段可以“修改要求”“放弃这单”或让角色重新选择。**没有点击最终确认前，麦当劳订单不会被创建。**

## 第六步：确认、付款和查看进度

点击确认时，Owlpost 会再次向麦当劳核对菜单、规格和价格：

- 如果价格或餐品内容发生变化，确认函会要求你重新查看，不会沿用旧价格直接下单；
- 如果核对一致，才会创建一次订单；重复点击不会创建第二单；
- 创建成功后，点击付款会打开麦当劳官方付款页面；Owlpost 不读取银行卡、支付密码或付款结果页面里的秘密；
- 从付款页回到游戏后，确认函会刷新订单状态；也可以稍后手动点击刷新。

付款前如果看到餐品、金额、地址或门店不对，请不要继续支付。已经创建的订单能否取消、退款或修改，以麦当劳官方页面、门店和客服给出的能力为准；Owlpost 不承诺代为取消。

## 开关、重新绑定与解除连接

- **关闭开关**：停止准备和确认新订单，但已有订单仍可尝试查询进度。
- **重新绑定**：先验证新 Token；验证成功后才会替换旧连接。
- **需要重新绑定**：通常表示 Token 已失效、过期或被撤销，请回麦当劳控制台取得可用 Token。
- **解除连接**：停止用这条 Token 创建和查询后续请求；已经创建的订单仍应在麦当劳官方渠道处理。

## 常见问题

### 显示“点餐邮路暂未开放”

这表示当前 Owlpost 版本或服务器还没有打开这项能力。请保持开关关闭，等待发布说明；反复粘贴 Token 不会解决。

### Token 验证失败

确认没有复制空格、引号、`Bearer` 前缀或整段 JSON。再回麦当劳 MCP 控制台确认 Token 仍然有效。不要把 Token 发给他人帮忙检查。

### 找不到外送地址

确认 Owlpost 绑定的麦当劳手机号，和你保存地址时使用的是同一个账号。然后在麦当劳官方 App、小程序或点餐页面补全地址，再回来重新准备草案。

### 找不到餐品或门店

菜单、营业时间、库存、配送范围和优惠都由麦当劳实时返回。尝试换一家门店、换到合适时段，或者让角色重新查看当前可售餐品。

### 点击付款没有打开页面

浏览器可能拦截了新窗口。允许本站打开弹窗后，从原来的确认函再次点击付款；不要从聊天文字里复制陌生付款链接。

### 付款后状态没有变化

先回到 Owlpost，再点击确认函上的刷新。银行扣款、麦当劳订单和游戏状态不一致时，以麦当劳官方订单记录为准，并保留付款凭证联系麦当劳客服。

## 使用范围与安全提醒

- 使用麦当劳 MCP 服务前，你需要同意并遵守麦当劳中国的使用条款和 MCP 服务规则。
- 官方示例允许个人按非商业用途连接；公开收费、广告、订阅、流量变现或暗示官方合作前，需要另行确认书面授权范围。
- Owlpost 与麦当劳不存在教程之外的品牌合作或联名关系。
- 餐品、价格、优惠、配送、付款、取消和售后，以麦当劳官方信息为准。
- 永远不要把 MCP Token、完整地址、电话、付款资料发给角色或其他玩家。

:::success
最安全的顺序是：先在麦当劳账号准备好资料 → 申请 Token → 回游戏验证绑定 → 打开开关 → 私聊明确同意 → 检查确认函 → 亲自确认 → 在麦当劳官方页面付款。
:::
